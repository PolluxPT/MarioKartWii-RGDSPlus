RGDS+ experimental adapter - MIT license
=====================================
New files: egl_wayland.c, graphics_probe.c, input_info.c, launcher and PC helper.
Generated xdg-shell protocol files retain their original license notices.
The original game executable is unchanged. New code is a runtime EGL adapter;
it does not contain Nintendo assets, keys or code extracted from a disc.

Build on Linux with an AArch64 GCC cross compiler, EGL/GLES headers,
Wayland client headers/protocols and ARM64 Wayland client/EGL libraries:

  aarch64-linux-gnu-gcc -shared -fPIC -O2 -Wall -Wextra -Werror \
    egl_wayland.c rgds_runtime.c xdg-shell-protocol.c \
    -lwayland-client -lwayland-egl -ldl -o libmkw_wayland.so
  aarch64-linux-gnu-gcc -O2 -Wall -Wextra -Werror \
    graphics_probe.c -ldl -o graphics_probe
  aarch64-linux-gnu-gcc -O2 -Wall -Wextra -Werror \
    input_info.c -o input_info

The wrapper exports exactly the EGL entry points used by the supplied binary.
MKW_EGL_LIBRARY selects the wrapper. MKW_REAL_EGL optionally selects the system
Wayland-compatible EGL driver. No system EGL files are replaced.
MKW_OUTPUT selects a wl_output index, default 0. xdg-shell version 1 is used.
The stock game still uses SDL3 offscreen for events/audio/gamepads.
Fullscreen pixel dimensions must agree with MKW_FB_WIDTH/MKW_FB_HEIGHT.
