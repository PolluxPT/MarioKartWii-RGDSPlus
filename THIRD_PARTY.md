# Componentes e créditos

A licença MIT da raiz aplica-se apenas às adições da adaptação RGDS+. Os avisos originais de cada componente acompanham a aplicação em `APPS/MarioKartWii/licenses`.

| Componente | Origem / aviso |
|---|---|
| Continuação MKW-3DS | MiniBandit — alterações MIT; ver `MKW-3DS-LICENSE.txt` e `MKW-3DS-NOTICE.txt` |
| Port inicial MKW-3DS | dudewhat — o aviso original informa que a publicação inicial não tinha licença explícita; não está abrangida pela MIT desta adaptação |
| Port H700 e camada de compatibilidade | Matrioshka Brain — ver `H700-PORT-NOTICE.txt` |
| Kinoko | vabold — MIT |
| SDL3 | zlib |
| Partes de libctru e citro3d | zlib |
| noclip.website e gclib | MIT |
| Referências ogws e mkw | CC0 |
| Runtime GNU incluído pelo port H700 | Bibliotecas originais mantidas sem alteração; não abrangidas pela MIT da adaptação |

O ficheiro `Sources/mkw3ds-h700-source-v1.21.zip` é o arquivo de fontes fornecido no pacote original. O executável fornecido tem a etiqueta v1.22 e build ID `4ebfbdc15c1cc02b`. O arquivo v1.21 não é apresentado como reprodução exata do binário v1.22. O projeto não altera nem substitui os avisos relativos à base de terceiros.

As fontes da ponte RGDS+, do teste gráfico e do utilitário de diagnóstico estão disponíveis nesta pasta de projeto. A geração do executável principal depende dos projetos originais e das suas dependências.

O pacote não contém ROMs, CIAs ou dados de jogo convertidos. Uma imagem de ícone acrescentada pelo publicador conserva o seu próprio enquadramento de direitos; não é automaticamente abrangida pela licença do código.
