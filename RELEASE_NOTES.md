# Mario Kart Wii for RGDS+ — Complete package v1.1.0

## Português

Release completa: aplicação final RGDS+ + preparador PT/EN + builder H700 original + guias em ambos os idiomas.

1. Extrai o ZIP inteiro no PC.
2. Segue **INICIO_PT.md** para instalar as ferramentas uma única vez.
3. Coloca a tua ROM americana **RMCE01** em **ROM** (ISO, WBFS ou RVZ).
4. Abre **PREPARAR_ROM.bat**, escolhe Português e aguarda **PRONTO**.
5. Copia o conteúdo de **PARA_CONSOLA/APPS** para `APPS` do cartão TF2.

Não é preciso programar ou procurar o builder noutro pacote. Requer ferramentas gratuitas e ligação à Internet para preparar dependências públicas. RVZ usa DolphinTool; a ROM original é preservada. Não inclui ROM nem dados convertidos.

Os binários do jogo são os da versão final 1.0 já testada. Quem já tem a instalação funcional não precisa de converter novamente. Ícone opcional em `APPS/Imgs/MarioKartWii.png`. Outros modelos não foram validados; o cavalinho aguarda teste com uma mota desbloqueada.

## English

Complete release: final RGDS+ application + PT/EN preparation front-end + original H700 builder + guides in both languages.

1. Fully extract the ZIP on your PC.
2. Follow **START_HERE_EN.md** for the one-time tool setup.
3. Put your USA **RMCE01** disc image in **ROM** (ISO, WBFS or RVZ).
4. Open **PREPARAR_ROM.bat**, select English and wait for **DONE**.
5. Copy the contents of **PARA_CONSOLA/APPS** to `APPS` on the TF2 card.

No programming or separate builder download is needed. Free system tools and an Internet connection for public dependencies are required. RVZ uses DolphinTool; the original disc image is preserved. No ROM or converted game assets are distributed.

Game binaries are unchanged from the tested Final 1.0. Existing working installations do not need a new conversion. Optional icon: `APPS/Imgs/MarioKartWii.png`. Other devices are unverified; wheelies await a test with an unlocked bike.

Based on MiniBandit's MKW-3DS remake and Matrioshka Brain's H700 port. Original notices and credits are included.
